# webkocluk_mobile

Flutter mobile foundation for Web Kocluk app.

## Scope (Current)

- Firebase initialization and project wiring
- Email/password authentication
- User profile creation in Firestore (`student` / `parent` role)
- Role-based home routing
- Student teacher-note read flow by day

## Setup

1. Install Flutter SDK and verify:
	- `flutter --version`
2. Install Firebase CLI + FlutterFire CLI:
	- `npm i -g firebase-tools`
	- `dart pub global activate flutterfire_cli`
3. Login and configure:
	- `firebase login`
	- `flutterfire configure`
4. Run dependencies:
	- `flutter pub get`
5. Analyze and run:
	- `flutter analyze`
	- `flutter run`

## Firestore Model

See full model in `docs/architecture.md`.

Main collections:

- `users/{uid}`
- `student_program_notes/{studentId}/days/{dayKey}`

## Security Rules

Rule template is included in `firestore.rules`.

Deploy rules:

- `firebase deploy --only firestore:rules`

## Notes

- `lib/firebase_options.dart` currently contains placeholders and must be regenerated by `flutterfire configure`.
- Teacher write permissions are intentionally closed in the current rules template until teacher role/auth flow is defined.
